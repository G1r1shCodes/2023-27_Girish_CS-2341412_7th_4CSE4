\chapter{Project Description}

\section{Introduction}

The global industrial manufacturing vertical, particularly electrical wire and cable manufacturing, operates in a high-demand environment where operations, sales, and field teams must manage trade inquiries, technical datasheets, competitive tenders, and employee tasks efficiently. Traditional manual processes for customer engagement, lead generation, document editing, and task monitoring are slow, error-prone, and unsustainable for growing industrial enterprises.

\textbf{KDI Power Private Limited} is a prominent Indian manufacturer of high-quality electrical cables and wires (Aerial Bunched Cable, XLPE Power Cables, Control Cables, House Wires, Rubber Cables, and Instrumentation Wires). To modernize its operational and commercial processes, KDI Power commissioned the development of an integrated suite of Artificial Intelligence and Automation systems.

During my industrial internship from \textbf{29 June 2026 to 31 August 2026}, I served as an \textbf{AI \& Automation Engineering Intern} at KDI Power Private Limited. I was responsible for designing, building, and deploying five core software systems:
\begin{enumerate}[leftmargin=*,itemsep=2pt]
    \item \textbf{KDI Power AI WhatsApp Assistant \& Sales Dashboard:} Automated conversational sales bot on Meta WhatsApp Cloud API with Supabase pgvector RAG database and live glassmorphic web analytics dashboard.
    \item \textbf{KDI Lead Intelligence Engine:} 3-tier B2B lead discovery, Playwright web scraper, proxy rotation, website extractor, email validator, and Groq LLM scoring engine with automated Excel reports.
    \item \textbf{LinkedIn Tender \& Government Scheme Tracker:} Playwright CDP browser automation and Mistral AI summarization engine tracking competitor posts and government electrification orders (RDSS, DDUGJY).
    \item \textbf{AI PDF Reconstructor \& Editor:} Full-stack React 18 / Vite and FastAPI web PDF editor using MinerU layout detection, NVIDIA NIM VLM (Llama 3.2 90B Vision) for LaTeX math/tables, and Playwright PDF generation.
    \item \textbf{Google Sheets Task Automation Bot:} FastAPI webhook hosted on Render connected to Google Sheets API v4 service accounts and WhatsApp for automated employee task reminders and real-time IST time tracking.
\end{enumerate}

\section{Problem Statement}

The operations and commercial teams at KDI Power faced five critical operational bottlenecks:

\begin{enumerate}[leftmargin=*,itemsep=4pt]
    \item \textbf{Delayed Sales Turnaround on WhatsApp:} Manual handling of inbound product inquiries on WhatsApp led to missed leads during non-business hours.

    \item \textbf{High Cost of International B2B Lead Discovery:} Finding verified electrical cable distributors and utility contractors in export markets (such as South Africa) via manual search was slow and expensive.

    \item \textbf{Manual Competitor & Tender Tracking:} Manually checking LinkedIn posts for competitor updates (Polycab, KEI, Finolex, Havells) and government scheme updates (RDSS, DDUGJY) consumed hours daily.

    \item \textbf{Uneditable Technical Datasheet Scans:} Modifying scanned technical datasheets, cable spec tables, and math equations required manual re-typing.

    \item \textbf{Operational Task Tracking Overhead:} Following up on pending field tasks via manual phone calls lacked verified completion timestamps.
\end{enumerate}

\section{Project Objectives}

The primary objectives of the internship project were:

\begin{enumerate}[leftmargin=*,itemsep=4pt]
    \item \textbf{Automated Customer Support & Sales Bot:} Build a WhatsApp bot using Meta Cloud API, Groq LLM (`llama-3.3-70b-versatile`), and Supabase PostgreSQL (pgvector RAG) for automatic lead capture.

    \item \textbf{Glassmorphic Analytics Dashboard:} Create a single-page web dashboard for live lead management, catalog price editing, and Chart.js analytics.

    \item \textbf{Automated 3-Tier Lead Pipeline:} Build a Google Maps Playwright scraper with proxy rotation, website extractor, email validator, and Groq LLM scoring algorithm ($0-100$ scale).

    \item \textbf{Competitor & Scheme Intelligence Tracker:} Build a Playwright CDP session listener and Mistral AI summarization engine to output structured Excel reports (`Master_Tracker.xlsx`).

    \item \textbf{Hybrid AI PDF Editor:} Construct a React 18 + FastAPI web editor combining MinerU layout detection, NVIDIA NIM VLM for tables/LaTeX, and Playwright Chromium PDF generation.

    \item \textbf{Automated Task Reminder Service:} Deploy a FastAPI webhook service on Render integrated with Google Sheets API v4 and WhatsApp for automated reminders and IST time tracking.

    \item \textbf{CI/CD Cron Automation:} Configure GitHub Actions (`send_reminders.yml` & `keep_alive.yml`) to maintain server uptime and schedule periodic task dispatches.
\end{enumerate}

The scope of the project encompasses the following functional areas:

\textbf{In Scope:}

    \item Full-stack API and service development using Python 3.10+, FastAPI, Flask, and Streamlit.
    \item Browser automation using Playwright Chromium and CDP sessions.

\textbf{Out of Scope:}
\begin{itemize}[leftmargin=*,itemsep=2pt]

    \item High-voltage physical lab cable testing procedures.
\end{itemize}

\section{Methodology}

The project followed an agile, 6-phase engineering lifecycle:

\subsection{Phase 1: Discovery and Architecture Setup (Weeks 1--2)}
\begin{itemize}[leftmargin=*,itemsep=2pt]
    \item Requirements gathering for KDI Power's cable product catalog.
    \item Meta WhatsApp Developer App creation and Google Cloud Service Account configuration.
    \item Supabase PostgreSQL database schema initialization with pgvector extensions.
\end{itemize}

\subsection{Phase 2: Core Development (Weeks 3--5)}
\begin{itemize}[leftmargin=*,itemsep=2pt]
    \item Development of FastAPI webhook handlers for Meta WhatsApp Cloud API.
    \item Implementation of Groq AI conversational RAG engine.
    \item Building the glassmorphic HTML/CSS/JS sales analytics dashboard.
\end{itemize}

\subsection{Phase 3: Lead Intelligence & Scraping (Weeks 6--7)}
\begin{itemize}[leftmargin=*,itemsep=2pt]
    \item Building Playwright Google Maps scraper with proxy rotation.
    \item Developing website contact extractor and email validation pipeline.
    \item Creating the Groq LLM KDI Cable Scoring Engine and formatted Excel exporter.
\end{itemize}

\subsection{Phase 4: AI PDF Editor & OCR (Weeks 8--9)}
\begin{itemize}[leftmargin=*,itemsep=2pt]
    \item Setting up MinerU layout detection subprocesses on CPU to prevent VRAM OOMs.
    \item Integrating NVIDIA NIM (Llama 3.2 90B Vision) for LaTeX table and formula extraction.
    \item Constructing the React 18 + Vite interactive canvas UI.
\end{itemize}

\subsection{Phase 5: Task Automation & Integration (Weeks 10--11)}
\begin{itemize}[leftmargin=*,itemsep=2pt]
    \item Deploying `webhook.py` on Render connected to Google Sheets API v4.
    \item Building automated message parsers for employee `ok`/`done` replies with IST timestamping.
    \item Configuring GitHub Actions cron jobs (`send_reminders.yml` & `keep_alive.yml`).
\end{itemize}

\subsection{Phase 6: Deployment & Documentation (Week 12)}
\begin{itemize}[leftmargin=*,itemsep=2pt]
    \item End-to-end integration testing across all 5 projects.
    \item Preparing desktop batch executables (`RunTracker.bat`, `start_portable.bat`).
    \item Writing technical documentation, user guides, and internship report.
\end{itemize}
